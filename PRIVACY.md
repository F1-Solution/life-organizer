# Privacy Policy

_Last updated: 20 November 2026_

This policy covers **Claude Control**, a personal tool that its owner uses to organise their own Gmail inbox, read their own calendars and tasks, and build a private knowledge base. It is not offered to the public.

## Who can use it

The application is used only by its owner, signing in with their own Google account. No other users are expected or supported.

## Google data the application accesses

| Scope | Purpose |
|---|---|
| `gmail.modify` | Read message headers and content to group messages by sender and type, apply labels, archive, mark messages as read and create drafts when the owner asks. The application never sends, forwards or permanently deletes mail. |
| `gmail.settings.basic` | Create filters that label, archive or mark as read future mail from senders the owner has approved. The application never creates forwarding rules. |
| `calendar.readonly` | Read events to find recurring reminders. The application never creates or changes events. |
| `tasks.readonly` | Read tasks to find recurring items and saved links. The application never creates or changes tasks. |
| `openid`, `email`, `profile` | Identify the signed-in account. |

## How data is used and stored

- Data is processed on the owner's own computer and stored there, or on storage the owner controls.
- Data is not sold, shared with third parties, used for advertising, or used to train general-purpose AI models.
- Content may be passed to an AI assistant running on the owner's behalf, only to carry out the owner's own requests.
- OAuth tokens are stored encrypted on the owner's computer and can be revoked at any time from https://myaccount.google.com/permissions.

## Limited Use

The application's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion

Data is kept only as long as the owner needs it. Revoking access and deleting the local folder removes all of it.

## Contact

Questions about this policy can be sent to the support email shown on the application's Google consent screen.
