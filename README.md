# Life Organizer

A personal toolkit for organising Gmail, reading calendars and chats in read-only mode, and building a private second brain from saved links and notes.

- `tools/telegram/` reads Telegram chats in read-only mode (Telethon).
- `tools/outlook/` reads the classic Outlook calendar via COM, in read-only mode.
- `docs/` holds design notes.

Personal data (`inbox/`, `data/`, `output/`) stays on the local machine and is never committed.

See [PRIVACY.md](PRIVACY.md) for the privacy policy.
